# 循声虫族白盒使用入口

当前规则以《战斗系统细化 原案》和《ngj fps 敌人 技能 武器》为依据。完整调参、美术接入及目录约定见[开发指南](开发指南.md)，代码入口见[源码索引](源码索引.md)。

打开 `Assets/Game/SlugWhitebox/Scenes/SlugWhitebox.unity`。源码更新后，已有 Windows 构建需要重新构建才能包含当前规则。

| 输入 | 功能 |
| --- | --- |
| WASD / 鼠标 | 移动 / 转向 |
| 左键 / 右键 | 普攻 / 武器噪值技能 |
| 1 / 2 或滚轮 | 切换两把出战武器，默认霰弹与火箭筒 |
| Z / X / C，再按 Q | 选择嘶鸣 / 撼地 / 共鸣并释放 |
| R / Esc | 重开 / 暂停或继续 |

噪值达到上限时死亡，停止开火和受击后自然降低。武器技能消耗噪值；声腺技能每次消耗 1，声腺初始/上限 2、默认每 10 秒恢复 1，击杀掉落额外补充。中重甲在前摇、攻击和眩晕期间暴露弱点。

按 01 → 02 → 03 清场推进，最后进入 EXIT 结算。分区敌人数为 8/11/14。翼怪、甲壳怪与两种眼虫已接入逻辑预制体，黄/紫眼虫均为觅音虫外观变体。霰弹显示撼音体；爪型枪作为火箭筒外观，使用直线白板弹体。正式动作动画待制作。

菜单“重新生成白盒”会覆盖场景几何与导航数据；手工搭关卡时不要执行该菜单。修改环境后按需重新烘焙导航。数值属于可调整的测试基线。
