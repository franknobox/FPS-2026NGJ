# 循声虫族 · 可试玩白盒

按《ngj 声 fps slug.pdf》制作，验证「声波削弱 → 射击击杀 → 拾取声腺 → 再施放」循环。关卡与敌人使用灰白方块、胶囊和球体占位，第一人称武器使用现有 FPS Engine 素材包的模型与动画。屏幕仅显示声腺计数器，启动直接进入游戏。

## 启动

双击项目根目录的 `试玩循声虫族白盒.cmd`，或运行 `Builds/SlugWhitebox/SlugWhitebox.exe`。Windows 64 位，1280×720 窗口。

分享请使用 `Builds/循声虫族白盒-Windows.zip`，完整解压后启动 exe；Data、MonoBleedingEdge、UnityPlayer.dll 等文件需要保留在 exe 旁边。

## 操作

| 输入 | 功能 |
| --- | --- |
| WASD / 鼠标 | 移动 / 转向 |
| 左键按住 | 开火 |
| 右键点按 | 施放当前声音技能 |
| 1 / 2 / 3 / 4，或滚轮 | 步枪 / 高伤左轮 / 霰弹枪 / 武士刀 |
| Z / X / C | 选择裂甲 / 减速 / 震荡技能 |
| R | 重新开始 |
| ESC | 暂停 / 继续 |
| Alt+F4 | 退出 |

默认装备步枪与裂甲技能。沿 01 → 02 → 03 推进，每区清敌后进入下一片区域；最后到 EXIT 结束，按 R 再玩。死亡后 1.5 秒自动重开。没有跳跃、冲刺、开镜、开始菜单或结算界面。

## 试玩机制

- 声腺初始 100，缓慢回复 2.5/秒；击杀掉落白色小方块，靠近自动吸附，每只补充 18，最多 100。计数器显示向下取整后的数量。
- 三技能消耗 25 / 35 / 45 声腺，分别施加锥形易伤、周身减速与短硬直、周身易伤与较长硬直。易伤敌人变白，减速敌人变浅灰；有墙体遮挡时不生效。
- 武器无限弹药，前三种独立过热，达到 100 停火，冷却到 30 恢复；可换枪继续射击。近战不积热。高伤单发枪目前不贯穿多个敌人。
- 胶囊为普通近战，立方体为重型近战，球体为远程敌人。NavMesh 寻路，三片区域共 33 只。
- 生命与热量保留在后台参与战斗，按要求不显示 UI。没有局外升级、资源条、技能轮盘、准星或敌人状态面板。

## Unity 修改

版本 6000.3.28f1，URP / Input System / AI Navigation。

1. 打开 `Assets/SlugWhitebox/Scenes/SlugWhitebox.unity`，点击 Play 即可试玩。
2. `Assets/SlugWhitebox/Settings/WhiteboxTuning.asset` 调整声腺、伤害、热量、生命和敌人数。
3. 「白盒几何 · 单位为米」下移动墙与掩体；地面网格间隔 2 米。修改阻挡后重新 Bake 根对象的 NavMeshSurface。
4. 「敌人出生点」调整位置，sector=0–2，kind=0–2。每区预留 14 个点。
5. 菜单「循声虫族 / 构建 Windows 白盒」打包当前已保存场景。「重新生成白盒」会覆盖生成场景与导航数据，参数资产保留。

声音使用运行时合成的射击、命中、技能和拾取反馈。四种武器的 FBX 原本是 Git LFS 指针，已从原项目仓库恢复，并逐一核对文件大小及 SHA256，记录见 `Docs/weapon-recovery.json`。武器保留原有手臂、骨骼、待机与开火/挥刀动画，使用中性灰材质适配白盒；不依赖缺失的贴图或原素材包的角色控制器。数值用于测试，仍需人工试玩调节难度和手感。

菜单「循声虫族 / 替换为素材包武器」仅更新武器，不重建关卡；「重新生成白盒」也会默认使用这四种武器。

## 白盒参考与验证

参考：[The Level Design Book / Blockout](https://book.leveldesignbook.com/process/blockout)。白盒是用简单几何体检验关卡尺度、移动路线、掩体和战斗的粗略可玩关卡。参考样品为页面内《使命召唤：现代战争》Docks 的 blockout / final 对照与《Neon White》Smackdown。

自动验证结果：`Builds/Verification/smoke-report.json`；实机截图：`whitebox-combat.png`、`whitebox-exit.png`、`weapon-live-1.png` 至 `weapon-live-4.png`，以及对应的 `weapon-fire-*.png`。本次武器构建日志：`Logs/weapon-build.log`。

传入 `--slug-smoke` 可运行机制与完整流程验证；脚本调用实际开火、技能、寻路和移动方法。完整通关阶段持续补充玩家生命，仅验证流程与机制，不代表人工手感或难度测试。
